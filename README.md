# Database-of-Global-Riverine-Nutrient-Loads-and-Associated-Water-Discharge

This database contains monthly riverine nutrient load and corresponding water discharge data used for cross-continental active and legacy nutrient-source quantification. The database includes two nutrient datasets: total nitrogen (TNDATA) and total phosphorus (TPDATA).

Each .txt file represents one monitoring station. The first six lines provide station metadata, including station ID, water type, country name, latitude, longitude, and data units. The time-series data start from the tenth line. In the data table, the first column is the date in year-month format, the second column is water discharge (Q, m³/s), and the third column is nutrient load (L, mg/s).

Nutrient observations were compiled from 11 global and national monitoring databases, including the GEMStat database of the Global Environment Monitoring System for Freshwater (GEMS/Water) Programme, GLORICH, the European Environment Agency Datahub, the U.S. Water Quality Portal, the USGS National Water Quality Network nutrient and pesticide dataset, Victoria’s Water Measurement Information System, the Murray-Darling Basin Authority, the Swedish University of Agricultural Sciences Miljödata MVM database, LAWA, Japan’s Ministry of the Environment water-quality portal, and the Estonian Environment Agency KESE database.

The corresponding river discharge data were obtained from the Global Runoff Data Centre, World Meteorological Organization (2025).
